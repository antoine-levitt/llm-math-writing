Four-condition Astra/max writing experiment — results
===================================================

All four fresh runs completed successfully. The earlier pilot is excluded.
The four user prompts were submitted verbatim and are recorded per case.
All used GPT-6-Astra/max, Codex 0.166.0, the same inputs and configuration,
and three available concurrent subagent slots. The runs were sequential
in the recorded shuffled order: review, plain, explicit, explicit_review.

Cached input and reasoning output are subsets of the corresponding totals.
Usage sums unique response records across root and descendant threads;
copied parent histories are deduplicated. Both review conditions used
three subagents for initial proof work and two manuscript-review rounds.
The other conditions chose not to use subagents. All actual threads were
Astra/max. results.csv also gives reasoning, uncached input and total tokens.

Minutes are monotonic launch-to-exit wall time, including agent/tool waits,
excluding preparation and archival. Provider GPU time is not exposed.
Per-agent turn durations and local child-process CPU diagnostics are retained
in usage.json/timing.json; they should not be interpreted as GPU time.

Execution audit
---------------
All root and reviewer turns completed; no abandoned turns or CLI failure
events were found. Response sums match native cumulative counters. Final
manuscript PDFs are readable, their build logs have no LaTeX warnings or
errors, and the delivered PDF copies match their final builds.
All four bibliographies contain only Reed–Simon references.

Exact prompt text is present in every native root trace. Input hashes and
the CLI hash are unchanged. Configurations match after substituting each
neutral workspace/state path, including paths used as filesystem-rule keys.
Offline startup-context checks matched after removing the task prompt and
transient identifiers. Private memory stores have zero generated entries,
database consistency checks pass, and temporary authentication copies were
removed. No online-access calls or accesses to the original paper or other
conditions were detected. The recorded sandbox preflights block those paths.

Recovered failures are retained: a malformed reviewer patch and an initial
LaTeX error in review; an unmatched revision patch in explicit_review;
and assorted searches with no matches, absent optional-tool probes, Git
status outside a repository, premature file reads, and incorrect lookup
paths. Subsequent successful commands/builds and completed reviews verify
recovery. See each case’s AUDIT.txt and audit.json for details.

No supervisor hints or edits were supplied to the experiment sessions.
The audit concerns execution, isolation, accounting and artifacts; it is
not a full independent mathematical correctness or writing-quality score.

A separate read-only cross-check confirmed all 308 unique responses across
ten threads against native counters, SQLite totals and root CLI usage.
It found no consequential discrepancy. See INDEPENDENT_AUDIT.txt.
